# Image Processor

`image_processor` — консольное C++ приложение для обработки BMP-изображений с помощью набора графических фильтров.

Проект реализует собственную работу с форматом BMP без использования сторонних библиотек для обработки изображений. Фильтры применяются последовательно в том порядке, в котором они указаны в аргументах командной строки.

## Возможности

Приложение поддерживает:

- чтение 24-битных BMP-файлов без сжатия;
- сохранение результата в BMP;
- последовательное применение нескольких фильтров;
- обработку некорректных аргументов;
- вывод справки при запуске без аргументов;
- модульную архитектуру с отдельными классами для BMP, фильтров, парсинга аргументов и пайплайна обработки.

## Поддерживаемый формат изображений

Программа работает с BMP-файлами следующего формата:

- 24-bit BMP;
- без сжатия;
- DIB header: `BITMAPINFOHEADER`.
